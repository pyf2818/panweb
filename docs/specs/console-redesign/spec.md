# 控制台三栏科幻工作台改造规格

版本：1.0 · 状态：实现中
范围：`ui/src/`、`ui/index.html`（构建产物）、`src/panweb/commands.py`（新增）、
`src/panweb/ui_actions.py`（新增只读指令解析接口）、`src/panweb/entries.py`（节点健康字段）。
不在范围：`share.py`、`proxy.py` 分享页渲染、`publish.py`/`cli_commands.py`（已满 500 行，
本次不改）。

## 1. 目标

把默认页从「侧栏 + 卡片堆叠」改为三栏工作台：

| 栏位 | 角色 | 内容 |
| --- | --- | --- |
| 左栏 | 历史与资产 | 应用列表（运行中/已停止/已过期）、搜索、选中项变更时间线 |
| 中栏 | 对话式发布 | 指令输入、实时步骤消息流、成功回执（网址/分享链接/二维码）、失败原因与重试 |
| 右栏 | 进程可视化 | 内置代理 / cloudflared 隧道 / 源应用三节点存活与健康脉冲、请求量、最近访客、当前网址、隧道重建次数 |

全局导航（工作台 / 动态与提醒 / 连接 Agent / 终端 / 系统与数据）收进中栏顶部的标签条，
不再占用独立侧栏，保证「三栏」在 1440×900 下完整可见。

## 2. 保留的既有功能

发布端口、发布文件夹、启动 npm 项目、应用列表与详情抽屉、停止、访客视角自检、
访问口令与有效期、分享页入口、发布历史时间线、真终端（term）、设置与诊断、云端托管、
许可、通知中心、⌘K 命令面板、文件夹选择器、主题说明（固定深色）。以上入口至少保留一个。

旧「发布」弹窗继续作为「高级发布」：口令/有效期/标题/说明/风险确认/云端托管等完整表单
都还在，指令流不替代它。

## 3. 数据来源（只用现有 API）

| 数据 | 来源 |
| --- | --- |
| 环境、应用列表、PV、最近访客、通知、许可 | `GET /api/state`（沿用 4 秒轮询，不新增更高频轮询） |
| 选中项时间线 | `GET /api/history?id=&limit=` |
| 发布默认值（端口/文件夹/有效期/分享） | `GET /api/publish-defaults` |
| 指令解析 | `POST /api/command`（新增，只解析不执行） |
| 发布/文件夹/启动 | `POST /api/publish`、`/api/pages`、`/api/run`（`async:true` + `GET /api/job` 轮询） |
| 停止/自检 | `POST /api/stop`、`POST /api/check` |
| 节点存活 | `/api/state` 的 `apps[].nodes`（新增字段，由 `entries.core_list` 用现有 `pid_alive`/`port_listening` 计算） |

`/api/state` 仍是唯一周期数据源。右栏不在 4 秒之外新增轮询；时间线只在选中变化、
发布/停止完成后按需拉取。

## 4. 指令语法（保守解析）

后端 `src/panweb/commands.py` 纯函数解析，前端只拿结构化结果，绝不把自由文本塞给发布接口。

```
发布 [端口 | 文件夹] [pin=xxxx] [有效期=1h|1d|7d] [分享=开|关] [名称=xxx]
启动 [文件夹] [同上选项]
停止 [全部 | 端口 | id | 当前]
检查 [端口 | id | 当前]
帮助
```

- 动词别名：`发布`/`publish`、`启动`/`run`、`停止`/`stop`、`检查`/`check`、`帮助`/`help`。
- 目标：纯数字 → 端口（1–65535）；含 `/`、以 `~`/`.` 开头 → 文件夹；省略 → `null`
  交给 core 的既有默认（上次端口 / 当前目录）。
- 选项键：`pin`、`有效期`/`expires`、`分享`/`share`、`名称`/`name`。
  分享缺省时用 `/api/publish-defaults` 的 `share`；有效期缺省沿用默认值。
- 长度上限 200 字符；拒绝换行/控制字符与 `; | & $ > < \` ` 等 shell 形状字符；
  分词用 `shlex`（支持带引号路径），不做任何 shell 执行。
- 解析失败返回 `invalid_command`，附带可用示例；不产生任何发布动作。
- 高风险端口（如 Ollama/数据库）在指令路径直接拒绝并指向「高级发布」勾选风险确认，
  避免绕过既有风险确认。
- 口令只在前端内存与 job 请求体里出现：不写 localStorage、不进事件流、不进对话回执。

## 5. 右栏节点语义

| 节点 | 有数据 | 状态 |
| --- | --- | --- |
| 内置代理 | `proxy_port` 存在 | `server_pid` 存活且代理端口监听 → 在线；否则离线 |
| cloudflared 隧道 | 条目 `pid` 存在 | `pid` 存活 → 在线；否则离线 |
| 源应用 | `kind=port` | 目标端口监听 → 在线；否则离线 |
| 源应用（静态） | `kind=pages` | 目标目录存在 → 在线；否则离线 |

直连发布没有代理节点：显示「未启用（直连发布）」，不假装在线。字段缺失一律「未知」。
不使用随机数、不伪造心跳；没有选中项时提示从左侧选择，不画假拓扑。

健康脉冲：仅在线节点做呼吸（`box-shadow` + `opacity`）与连线流动；
离线节点静止灰色，未知节点虚线环。`prefers-reduced-motion: reduce` 时全部关闭。

## 6. 视觉与动效清单

- 深空底色（`#05080d` 一带）、冷青/冰蓝霓虹强调、等宽字体用于网址/端口/时间。
- 细网格底纹 + 极淡扫描线（`repeating-linear-gradient`，不遮挡文字）。
- 卡片改为「面板 + 细边框 + 克制辉光」，不做满屏发光噪点。
- 动效：节点呼吸、连线流动、新消息淡入上浮、发布进度点闪烁、扫描线缓移。
- 所有动效纯 CSS / 原生 JS；不引 CDN、不加 npm 依赖。
- 深色为唯一主题；顶部不再放亮/暗切换，设置页写明「本次控制台固定深空主题」。

## 7. 降级与移动端

- 数据未到：右栏显示「未知」/「读取中」，不显示绿色在线。
- `/api/state` 失败：保留上一帧数据并提示，右栏节点全部转「未知」。
- 窄屏（≤900px）：三栏折叠为单栏；左栏变抽屉（顶部「资产」按钮打开），
  右栏变底部状态抽屉（「进程」按钮打开）；底部指令输入常驻。
- 390×844：按钮点击区 ≥48px，输入字号 16px（防 iOS 缩放），
  顶栏标签横向滚动，不出现横向溢出。
- 无 JS 环境：页面至少显示静态标题与「需要启用 JavaScript」提示（现有 script 已覆盖）。
- 终端页保持原有全幅体验，左/右栏在非工作台页收起，避免挤压 xterm。

## 8. 安全边界（不得放宽）

- 控制台仍只绑定 `127.0.0.1`；Host/Origin 校验、`application/json` 校验不变。
- 路径与 dotfile 拒绝、PIN 不落盘、口令不进分享页 HTML 均沿用现有实现。
- `/api/command` 只做解析：不执行命令、不读任意文件、不回显口令。
- 左栏搜索只在内存过滤 `STATE.apps`，不引入后端搜索接口。
- 指令路径拒绝高风险端口，不能绕过风险确认。

## 10. 已知取舍

- 指令解析不覆盖标题/说明/云端托管；这些仍走「高级发布」。
- 高风险端口指令直接拒绝，需要风险确认时用高级发布。
- 右栏为 4 秒粒度，不是毫秒级实时；请求量来自聚合 PV，最近访客来自内存快照。
- 窄屏单栏下不能同时看时间线与拓扑，需要抽屉切换。
