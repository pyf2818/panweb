# 常驻三栏工作台 Spec（去掉对话式工作台）

## Why

当前工作台的中栏是“对话式发布”：输入框 + 消息流 + 自然语言解析。它把发布、停止、自检等能力藏在“会打字”的前提里，预览、表单、指令三种任务还要互相抢位置。同时顶栏没有固定、通知与主题控件挤在一起。本轮把工作台改成**常驻三栏 + 快捷指令区**：左栏管资产、中栏固定承担预览/新建/快捷指令、右栏保持详情，任何页面切换都不再藏掉三栏。

## What Changes

- **中栏重写**：移除对话输入框、消息流、上翻历史与 `/api/command` 接线；改为“预览 / 新建表单”两种主态 + 常驻快捷指令带。
- **新建应用就地化**：左栏顶部新增「＋ 新建应用」，中栏切到表单；来源为端口 / 文件夹 / 启动项目（云端托管保留为次级来源）；提交成功自动选中新条目并回预览。
- **预览 iframe**：只加载本机已发布条目对应的代理端口或源端口；禁嵌/不可达给出可读降级与「打开」。
- **顶栏固定**：`position: sticky`，滚动不动；主题（跟随系统/浅色/深色）与通知（铃铛 + 未读徽标 + 下拉面板）改为两个独立、带文字的控件。
- **移除**：`js/composer.js`、`commands.js` 中的对话执行入口、发布弹窗里的“独立挡死三栏”定位（表单内容复用，弹层仅保留文件夹选择器/云端托管等工具型弹层）。
- **保留**：后端 `commands.py`、`/api/command`、右栏全部详情与吸底操作、左栏过滤/时间线、主题与折叠记忆、`aria-live`。

**BREAKING**（仅控制台内部）：`Cmd/Ctrl+K` 不再聚焦输入框，改为聚焦快捷指令区；`↑` 回填指令历史取消。

## Impact

- Affected specs：`workbench-usability`（右栏、左栏、通知、无障碍基线保持不变）。
- Affected code：
  - UI：`ui/src/index.html`、`ui/src/partials/pages.html`、`partials/overlays.html`、`ui/src/js/publish.js`、`workbench.js`、`apps.js`、`commands.js`、`core.js`、`workspace.js`、`boot.js`、新增 `stage.js` / `preview.js` / `quickbar.js` / `notify.js`、`styles/console.css` / `workbench.css`
  - 后端：`ui_actions.py` 增加只读 `GET /api/preview?id=`（不改 `publish.py` / `cli_commands.py` / `share.py`）
  - 测试：`tests/test_preview_api.py`（新）、`tests/test_ui_contracts.py`

## 状态说明

1. **空态 / 零条目**：中栏显示三步引导（选择要发布 → 确认能被访问 → 发送给别人）+「扫描本机端口」；左栏顶部仍可新建。
2. **选中活动条目（预览态）**：工具条显示名称、打开、复制、刷新、停止、重新发布；iframe 加载本机地址。
3. **选中已停止 / 已到期**：中栏不加载 iframe，显示“已停止 · 右栏可重发”与「打开上次链接」；右栏展示快照信息，重发按钮可点。
4. **新建态**：来源 tab（端口/文件夹/启动项目；云端托管为“高级”次级入口）+ 名称/标题/说明/口令/有效期/分享；提交中显示步骤、失败保留表单可重试；成功自动选中新条目回预览。
5. **发布中**：快捷指令与提交按钮禁用，步骤区滚动到可见。
6. **云端托管条目**：不提供本地预览，显示“云端托管不提供本地预览，请用打开”。
7. **禁嵌 / 不可达**：iframe 区域替换为降级卡：“该应用禁止内嵌，请用『打开』”或“本机预览加载失败”，附打开按钮。
8. **通知面板**：收起 / 展开；未读徽标随 4 秒状态刷新更新；全部已读后徽标归零；点击条目跳转并关闭面板。
9. **主题**：跟随系统 / 浅色 / 深色三态，顶栏控件带图标 + 文本 + 可访问名称。

## iframe 安全与降级

- 前端不拼接任意 URL。iframe `src` 只来自 `GET /api/preview?id=<entry-id>` 返回值。
- 后端解析：只接受 `STATE` 中真实存在的条目；`hosted` / 已停止 / 快照 / 未知 id → `ok:false`。
- 允许的 src 仅两种：`http://127.0.0.1:<proxy_port>/`（有代理）或 `http://127.0.0.1:<port>/`（直连端口）；禁止 `a.url` 公网地址、用户输入 URL、`file://`、任意 host。
- 后端对目标做一次本地 `HEAD`/`GET` 探测，读取 `X-Frame-Options` 与 `Content-Security-Policy` 的 `frame-ancestors`：
  - `DENY` 或 `frame-ancestors 'none'`/非本机 → `embeddable:false, reason:"该应用禁止内嵌，请用打开"`；
  - 连接拒绝/超时 → `embeddable:false, reason:"本机预览加载失败，请用打开"`。
- 前端 iframe：`sandbox="allow-scripts allow-same-origin allow-forms allow-popups"`、`referrerpolicy="no-referrer"`；再叠加 8 秒加载超时 → 降级卡，绝不白屏。
- 预览不写入口令、不带 `Authorization`；口令应用先在分享页验证，预览只展示本机代理的公开响应。

## 通知面板数据来源与刷新

- 未读徽标：沿用 `STATE.activity`（`/api/state` 4 秒刷新）与 `localStorage["panweb-read-ts"]`，不新增轮询。
- 面板内容：展开时请求一次 `GET /api/history?limit=20`（现有事件流，含 `entry_id`），不随 4 秒刷新重复拉取；收起后丢弃。
- 点击条目：用 `entry_id` 调 `selectAsset(id)`（快照 id 同样可选中）；已不存在的条目只显示文本，不跳转。
- 系统通知逻辑（权限、去重、重要事件）保持不变。
- 事件流不回写口令明文；面板文案沿用事件 `text`。

## ADDED Requirements

### Requirement: 常驻三栏
系统 SHALL 在工作台页保持左栏（资产 + 新建）、中栏（预览/表单/快捷指令）、右栏（详情）同时可见；切换功能页与滚动不隐藏三栏。

#### Scenario: 切换到其它页面再回来
- **WHEN** 用户点击「系统与数据」再返回「工作台」
- **THEN** 三栏仍按原宽度与选中态恢复，中栏仍是预览/表单而非对话。

### Requirement: 快捷指令区
系统 SHALL 在中栏提供常驻指令带；带参数项打开表单且预选来源，无参数项直接调用既有接口。

#### Scenario: 停止当前
- **WHEN** 有选中条目时点击「停止当前」
- **THEN** 调用既有 `/api/stop`，停止后右栏切快照态，`aria-live` 播报结果；不出现消息流。

### Requirement: 本机预览
系统 SHALL 只允许 iframe 加载当前条目对应的本机代理/源端口，并对禁嵌与不可达给出降级文案。

#### Scenario: 上游禁止内嵌
- **WHEN** 目标返回 `X-Frame-Options: DENY`
- **THEN** 中栏显示“该应用禁止内嵌，请用打开”，不渲染空白 iframe。

### Requirement: 通知面板
系统 SHALL 让顶栏通知成为独立控件，未读徽标来自现有状态刷新，面板内容来自 `/api/history`，点击可跳转条目。

### Requirement: 顶栏固定与主题
系统 SHALL 使顶栏 `position: sticky` 常驻顶部，并提供主题与通知两个视觉可区分的控件。

## MODIFIED Requirements

### Requirement: 中栏可发现性（替代对话式）
原“输入框 + 语法提示 + ↑ 历史”全部移除；可发现性由快捷指令带与新建表单承担。`Cmd/Ctrl+K` 聚焦快捷指令区。

## REMOVED Requirements

### Requirement: 对话式工作台
**Reason**：对话把能力藏在“会打字”的前提里，与预览/表单抢位置，且需要维护一套前端语法提示。
**Migration**：见能力映射表；`commands.py` 与 `/api/command` 保留给 CLI/MCP。
