# 验收清单：常驻三栏 + 快捷指令区

## 布局

- [x] 桌面 1440×900 同时可见左栏（新建入口 + 资产 + 过滤 + 时间线）、中栏（预览/表单 + 快捷带）、右栏（详情 + 吸底操作）。
- [x] 切换「系统与数据」「动态与提醒」等页面再回工作台，三栏结构与选中态保持。
- [x] 顶栏 `position: sticky`，页面滚动 400px 后仍固定在顶部。
- [x] 主题与通知是顶栏两个独立控件，各自有文字/图标与可访问名称，未被压成图标堆。

## 中栏

- [x] 选中活动条目时中栏内嵌 iframe，工具条含打开、复制、刷新、停止、重新发布。
- [x] 点击左栏「＋ 新建应用」中栏就地切表单，不跳页、不出现挡死三栏的全屏模态。
- [x] 表单含端口/文件夹/启动项目三种来源，以及名称、标题、说明、口令、有效期、分享开关。
- [ ] 提交成功后自动选中新条目并回到预览。**（quick tunnel 429，未能端到端验证；表单提交链路与错误展示已验证）**
- [x] 快捷带常驻：发布端口/发布文件夹/启动项目/停止当前/检查一下/扫描端口；带参项填表不执行，无参项直接执行。
- [x] 对话输入框、消息流、上翻历史、前端 `/api/command` 调用均已移除；`commands.py` 与接口本身保留。

## 能力不丢失

- [x] 发布、停止、改口令、重新自检、重发、二维码、复制、打开各有按钮或表单入口（对照映射表逐项点检）。
- [x] 停止条目仍可从右栏「用同样配置重新发布」；快照态不出现死按钮。

## iframe 安全

- [x] iframe `src` 只来自 `GET /api/preview?id=`，前端不拼接外部 URL。
- [x] 后端只返回 `127.0.0.1` 的代理端口或源端口；hosted / 未知 / 已停止返回 `ok:false`。
- [x] `X-Frame-Options: DENY` 或 `frame-ancestors` 禁止时显示“该应用禁止内嵌，请用打开”，不白屏。
- [x] 连接失败或 8 秒超时显示可读降级卡 + 打开按钮。
- [x] iframe 带 `sandbox` 与 `referrerpolicy`，不携带口令或凭据。

## 通知与存储

- [x] 未读徽标来自 `/api/state` 的 activity 与 `panweb-read-ts`，无新增轮询。
- [x] 面板展开时拉一次 `/api/history?limit=20`，点击条目可跳到对应资产并关闭面板。
- [x] 通知文案与事件流不含口令明文；口令不进 DOM 属性、localStorage、sessionStorage。
- [x] 主题只存枚举、折叠/过滤/时间线只存布尔或枚举，均有清理路径。
